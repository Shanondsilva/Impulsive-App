Implementation details:
- Create a score session ledger using DataStore named score_sessions.
- Store up to 50 score sessions locally.
- Store: id, game type, score, completedAt, durationSec, urgeBefore nullable, urgeAfter nullable, outcome, validCompletion.
- Create ScoreRange: Today, Week, All-time.
- Create ScoreGameType including Reflex Override, Pattern Break, Block Cascade, Urge Survival, Fluid Regulation, and fallback types for later games.
- Create ScoreSessionOutcome: Walked away, Continued with intention, Completed, Replayed, Abandoned.
- Build dashboard calculations from real records:
  - Control Score = filtered control points + current level points.
  - Games completed = valid sessions in selected range.
  - Best game = highest scoring valid game in selected range.
  - Total Control Points = sum of computed control points in selected range.
  - Safe Exit count = Walked away outcomes in selected range.
  - Best Safe Exit streak = consecutive Walked away valid outcomes.
  - Average Urge Drop = average of urgeBefore - urgeAfter only when those values exist.
  - Best Urge Drop = max positive urge drop only when logged.
  - Personal Bests by game = all-time per-game best and previous score.
  - Recent Sessions = last 10 sessions in selected range.
